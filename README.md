# Portfolio de Romulo Pontes Menon

Este é um simples portfolio web estático para apresentação profissional.

## Conteúdo

- Informações pessoais
- Breve descrição
- Link para LinkedIn

## Hospedagem na Vercel

Para hospedar este site na Vercel:

1. Crie uma conta em [vercel.com](https://vercel.com) se ainda não tiver
2. Instale o CLI da Vercel (opcional):
   ```
   npm i -g vercel
   ```
3. Faça deploy através do dashboard:
   - Faça upload deste projeto para um repositório no GitHub
   - Conecte sua conta Vercel ao GitHub
   - Importe o repositório do GitHub na Vercel
   - Vercel irá detectar automaticamente as configurações e fazer o deploy

Alternativamente, você pode usar o CLI da Vercel:
```
vercel login
vercel
```

## Desenvolvimento local

Para visualizar o site localmente, basta abrir o arquivo `index.html` em qualquer navegador moderno.
